The Kingdom of Aurora is an "Open World" that has grown significantly in scope. The technical rendering of this world has shifted from a segmented approach to a full-map draw.

## Geography and Map Evolution
- **The 1/32 Constraint:** Initially, the game only rendered 1/32 of the map at a time to save performance.
- **The Full Render (v0.12):** The "Updated Visuals" patch (v0.12) enabled the drawing of the entire game map. This expansion included the removal of invisible walls, although some still persist.   
- **Terrain Expansion:** New territories were added in v0.09, specifically designed to host new resource nodes like Ore and Coal.
